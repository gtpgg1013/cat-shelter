# 고양이 쉼터

힐링 픽셀아트 고양이 카페 시뮬레이션 게임

![Pixi.js](https://img.shields.io/badge/Pixi.js-v8-ff6b9d)
![Vite](https://img.shields.io/badge/Vite-v5-646cff)

## 소개

고양이 쉼터는 귀여운 고양이들과 함께하는 힐링 게임입니다. 절차적으로 생성되는 다양한 고양이들이 자유롭게 돌아다니며, 서로 관계를 맺고, 시간에 따라 다른 행동을 합니다.

**컨셉:** 단순한 규칙에서 창발적 행동이 나오는 살아있는 고양이 카페

## 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:5173` 접속

## 주요 기능

### 절차적 고양이 생성
- 무한한 외모 조합 (털색, 무늬, 눈색, 크기, 복슬복슬함)
- 6가지 털색: 오렌지, 크림, 브라운, 그레이, 블랙, 화이트
- 6가지 무늬: 단색, 태비, 삼색, 턱시도, 점박이, 투톤
- 성격 시스템: 호기심, 에너지, 친화성, 장난기, 대담함
- 희귀도: common, uncommon, rare, legendary
- 한글 이름: 모찌, 콩이, 두부, 감자, 구름, 달이...

### 시간 시스템
- 한국 시간(KST) 실시간 동기화
- 시간대별 조명 변화
  - 새벽 (5-7시): 핑크빛
  - 아침 (7-12시): 밝음
  - 오후 (12-17시): 따뜻함
  - 저녁 (17-20시): 주황빛
  - 밤 (20-5시): 어두움
- 시간대별 고양이 행동 변화 (오후엔 낮잠, 밤엔 폭주!)

### 사회 시스템
- 고양이간 호감도 (-100 ~ +100)
- 친한 고양이끼리 따라다니기, 같이 잠자기
- 그루밍 상호작용
- 싫어하는 고양이는 피하고 "샤악!"

### 이벤트 시스템
- 새 고양이 방문 이벤트
- 랜덤 줌이스 (폭주다냥!)
- 날씨 변화 (비 오면 창가에 모임)
- 생일 축하

### 인터랙션
- **쓰다듬기**: 머리, 턱, 등, 배, 꼬리 부위별 반응
- **간식주기**: 간식을 놓으면 고양이가 다가옴
- **장난감**: 마우스를 따라다니는 장난감

## 조작법

| 도구 | 사용법 |
|------|--------|
| 쓰다듬기 | 고양이 클릭 (부위별 다른 반응) |
| 간식 | 바닥 클릭으로 간식 배치 |
| 장난감 | 마우스 이동으로 장난감 움직이기 |

## 기술 스택

- **렌더링**: Pixi.js v8
- **번들러**: Vite
- **스타일**: 순수 픽셀아트 (Graphics API)

## 프로젝트 구조

```

├── main.js          # 엔트리포인트
├── game/
│   ├── Game.js      # 메인 게임 클래스

│   ├── SocialSystem.js   # 사회 시스템
│   ├── EventSystem.js    # 이벤트 시스템
│   ├── Treat.js     # 간식
│   └── Toy.js       # 장난감
└── style.css
```
